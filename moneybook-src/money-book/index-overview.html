🚀 打包成 APK(3 步搞定)

  1. 安装依赖并构建前端
    cd money-book
npm install
npm run build
  2. 同步资源到 Android
    npx cap sync android
  3. 用 Android Studio 打开并构建
    npx cap open android
# Studio 中: Build → Build APK(s)
# 产物: android/app/build/outputs/apk/debug/app-debug.apk

⚠️ 首次安装要做的事

  1. 把 app-debug.apk 拷到手机点击安装
  2. 打开 APP → "我的" 页面
  3. 点击"前往开启通知权限" → 找到"记账本"打开
  4. 点击"申请短信权限" → 允许读取短信
  5. 完成!现在支付通知会自动记账
